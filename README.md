## 💻 Sobre el Proyecto

Bienvenidos al repositorio oficial de **NanelOps**. Este proyecto es una *Single-Page Application* (SPA) diseñada para mostrar mi experiencia en administración de sistemas, infraestructura en la nube y DevOps. 

El diseño se aleja de lo convencional, adoptando una identidad visual **Dark Luxury Tech**. Inspirado en las terminales y *dashboards* de monitoreo, combina fondos oscuros y profundos con acentos en verde neón (`#39FF14`), brindando una vibra estilo "Matrix" pero con acabados de alta gama y elegancia profesional.

## ✨ Características Destacadas

- **Estética Inmersiva**: Uso intensivo de tarjetas con efecto *Glassmorphism* (cristal esmerilado) y textos con degradados suaves que resaltan sobre el fondo oscuro.
- **Interactividad Dinámica**: 
  - Fondo de partículas flotantes renderizado y animado con JavaScript puro.
  - Animaciones de conteo numérico que se activan de forma inteligente al hacer scroll.
  - Elementos visuales flotantes (3D) en la sección Hero (`hero_visual.png`).
- **Navegación Fluida**: Menú móvil intuitivo y una barra de navegación *sticky* que acompaña al usuario en toda la experiencia.
- **Diseño Responsivo**: Adaptado perfectamente para verse impecable desde monitores *ultrawide* hasta dispositivos móviles.

## 🛠️ Stack Tecnológico

* **Estructura**: HTML5 Semántico
* **Estilos**: CSS3 (Variables, Flexbox/Grid, Animaciones, Glassmorphism)
* **Lógica**: Vanilla JavaScript (Interactividad del DOM, observers de scroll, canvas de partículas)
